# Markdown Link Audit

A small, dependency-free command-line tool that checks links in Markdown files. It verifies local file targets and HTTP(S) URLs, prints each result, and exits with code `1` when a link fails.

## Requirements

Node.js 20 or newer. No installation step or npm dependencies are required.

## Usage

```sh
node src/cli.mjs README.md docs/guide.md
```

Use `--local-only` to skip network requests:

```sh
node src/cli.mjs --local-only README.md
```

Run the tests with `npm test`.

The checker handles inline Markdown links and images, plus angle-bracket autolinks. It ignores anchors, `mailto:`, `tel:`, fenced code blocks, and URLs with other schemes. Remote checks use a HEAD request first and retry with GET when a server does not support HEAD. Network checks have an eight-second timeout.

## Example output

```text
OK   README.md:5  docs/guide.md
FAIL README.md:8  https://example.invalid/  (request failed)

Checked 2 links: 1 passed, 1 failed.
```

## Limitations

This is a lightweight checker, not a complete Markdown parser. It does not resolve reference-style links or links generated by templates. Some sites block automated requests even when a page works in a browser.
